# 小玩学家 · 解题提示

一个 GitHub Pages 网站管理上百道题。每个关键词生成一个实际静态页面，可直接复制链接到公众号关键词回复。

## 页面与规则

- 网站： https://george351419-sys.github.io/answer/
- 示例： https://george351419-sys.github.io/answer/测试/
- 第一提示：进入该题页面后开始等待，默认 3 分钟。
- 第二提示：从第一提示计划解锁时间开始计算，默认再等 3 分钟。为空时不显示第二提示区域。
- 时间单位为分钟，可用小数，例如 `0.5` 是 30 秒。
- 同一浏览器保存每道题的开始时间，刷新、关闭后重新打开继续原进度；后台时间也计算。更换浏览器、清除浏览器数据或题目内容变更后重新计时。
- 这是静态页面交互，提示会包含在网页源码中，不适合保密内容或强制防作弊。浏览器时间也可被用户修改。

## 以后如何用 Excel 更新

1. 下载仓库 `imports/20261005-001.xlsx`，保留第一行七列表头。
2. 每行填一道题。前四列必填，后面三列选填。删除行也保留前四列。
3. 将本次文件命名为新的时间顺序文件名，例如 `20261006-001.xlsx`。同一天下一批用 `20261006-002.xlsx`。
4. 在 GitHub 仓库打开 `imports` 文件夹，选择 **Add file → Upload files** 上传，提交至 `main` 分支。
5. 打开 **Actions → 发布题目页面**，等待绿色成功标记。通常需要一两分钟。
6. 页面链接始终为 `https://george351419-sys.github.io/answer/关键词/`。中文关键词可直接使用，复制后浏览器可能自动转成百分号编码，效果相同。
7. 当次 Actions 运行底部可下载“页面链接清单”，其中 CSV 可用 Excel 打开，包含全部当前有效题目的链接。

| 字段 | 必填 | 说明 |
|---|---|---|
| 页面操作 | 是 | `新增` 或 `删除` |
| 关键词 | 是 | 链接最后一段；不能包含 `/ \ ? # %`，不能使用 `assets` 等保留名称 |
| 题目标题 | 是 | 页面上方的标题 |
| 提示1 | 是 | 第一条提示，支持换行 |
| 提示2 | 否 | 空白时整条第二提示不出现 |
| 第一提示间隔时间 | 否 | 分钟，默认 3 |
| 第二提示间隔时间 | 否 | 分钟，默认 3 |

所有批次按文件名顺序执行，因此请保留历史 Excel。`新增` 已存在的关键词表示更新；`删除` 不存在的关键词不会报错。删除后的旧链接显示获取链接的说明页，HTTP 返回 404。同一批次不要重复同一关键词。不要在模板中用公式，只用文本和数字。错误会阻止整次新版本发布，线上旧版本不受影响。

如果某批次填错，可以直接替换该批次文件；也可以追加一个更晚的纠正批次。更换关键词需先删除旧关键词，再新增新关键词。

## 本地预览

需要 Python 3，无第三方依赖：

```sh
python3 -m unittest discover -s tests
python3 scripts/build.py
python3 -m http.server 8000 --directory dist
```

访问 `http://localhost:8000/测试/`。`data/页面链接.csv` 是最近一次本地构建的清单；以线上 Actions 产物为最新清单。

部署使用 `.github/workflows/pages.yml`。仓库 Settings → Pages → Source 选择 **GitHub Actions**。页面没有第三方运行时脚本或字体服务。
